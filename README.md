This is a fix for use in TDSS to help minimize rng caused by a bug called RCS. In a nutshell, this can cause a random 1 second variance between runs, allowing some to just gain 1 second despite equal execution
This is in alpha rn. there are bugs rn im working on, and things to be improved, but core functionality is there ish
Setup incase people dont know how to use git:
1. install python (obviously)
2. download zip (ofc) and extract file.
3. Open folder, go into the TDSS-RCSFix.main folder (second one)
4. right click -> open in terminal, then run this: pip install -r requirements.txt
5. either run python RCSfix.py, or close out of terminal and double click the RCSFix.py file.
Actual setup:
1. go into a round, go to when the ready button appears. Click button for set coordinates, click on the light green part of the ready button. This should set the coordinates it clicks at.
2. click default delay, or custom and type your own time. Note: Default assumes rblx is opened through microsoft store (yes, this makes a difference). I have no idea if its different on other computers, hence why the custom input exists. please test this for me.
3. click start when the lobby timer is around 3-1. once the ready button appears slide mouse from left to right if your set position is on the left of the ready text, or right to left if its on the right.
